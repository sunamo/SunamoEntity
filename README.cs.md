# SunamoEntity

## Short description

NuGet balíček s entitními třídami a pomocnými typy, například ManageArtistDashTitle, SongFromInternet a ComplexInfoString, pro zpracování názvů skladeb a interpretů. Obsahuje testovací projekt a Runner. Je součástí sbírky PlatformIndependentNuGetPackages.
